# Tester apks
En el proyecto se encuentran escenas de diferentes experimentos que se han realizado.
TestEntornos/Assets/PROYECT/Scenes-> ForestLowPoly: escena para la cata de hamburguesas. Entorno de picnic con ventana interactiva para encuesta de percepción sensorial.
TestEntornos/Assets/PROYECT/Scenes-> PlaneScene: escena creada para la noche de investigadores, para ver cómo afecta el entorno y sonido en la percepcion del usuario.
